# DBus API

Application snaps can use [BlueZ DBus
API](https://www.bluez.org/bluez-5-api-introduction-and-porting-guide/) by
connecting to th bluez interface slot offered by the bluez snap.

Detailed documentation of the DBus API is provided by the BlueZ upstream
project [here](https://git.kernel.org/cgit/bluetooth/bluez.git/tree/doc).
